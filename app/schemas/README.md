# Shared Contract

The prototype uses `AnalysisRequest` for validated input and `AnalysisState` for all LangGraph node updates. The raw-data assessment exposes this callable interface:

```python
def run_analysis(
    request: AnalysisRequest,
    uploaded_file: BinaryIO | None,
) -> AnalysisState: ...
```

Each run uses only these artifact names:

```text
artifacts/<run_id>/
├── input.csv
├── cleaned.csv
├── transformations.json
├── charts/
├── report.html
└── metadata.json
```

The paths are generated by `app.services.build_artifact_paths`. The assessment phase saves `input.csv` and `assessment_report.html`; the approved-cleaning phase saves `cleaned.csv`, transformation metadata, and `report.html`.
